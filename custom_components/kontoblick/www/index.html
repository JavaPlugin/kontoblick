Mit Home Assistant verbinden

Kontoblick speichert deine Daten in deinem Home Assistant. Dafür braucht die App einmalig einen Zugangs-Token.

  1. Öffne Home Assistant und tippe unten links auf deinen Namen (Profil).
  2. Reiter „Sicherheit“ → ganz unten „Langlebige Zugangs-Token“ → „Token erstellen“, Name z. B. „Kontoblick“.
  3. Token kopieren und hier einfügen. Er wird nur auf diesem Gerät gespeichert.
